## Открытая проблема: балансы не проверены на живых API

Правки кошельков от 2026-08-18 покрыты офлайн-проверками на замоканном `fetch`,
но ни один запрос к настоящему API из облачной сессии не уходил — прокси
отдаёт 403 на CONNECT для `api.etherscan.io`, `solana-rpc.publicnode.com` и
`open-api.unisat.io`. Подробности — в `ЛЕТОПИСЬ.md` за 2026-08-18, развилка —
в `DECISIONS.md`.

Проверить руками на проде, с настоящими ключами, три вещи:

1. Solana-кошелёк показывает SPL-токены, а не один SOL.
2. Эфирный кошелёк не падает целиком, если одна сеть не ответила.
3. У BTC-адреса видны Руны — или строка «UniSat API key не задан», если ключа нет.
