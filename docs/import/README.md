# Импорт истории в «Срез»

Короткая памятка для владельца. Образец формата — `import-template.xlsx` (все числа в нём выдуманные).

## 1. Как собрать свой файл под шаблон

- **Два листа:** «Места» (справочник) и «Срезы» (одна строка на месяц). Приложение читает только их.
- **Места — колонки на листе «Срезы».** Имя колонки точно совпадает с именем на листе «Места». Новое место: новая колонка справа плюс строка на «Местах». Места рассчитаны примерно на 120 колонок (закрытые тоже считаются).
- **Закрытое место — 0**, колонку не удаляйте.
- **Одна строка на месяц.** Две строки за один месяц приложение отклонит.
- **Будущих строк быть не должно.** Заготовки вперёд (дата по формуле, суммы нули) приложение отклонит: такая строка заняла бы месяц, а срезы из приложения удалять нельзя. Это касается и текущего месяца: строку с датой 31.10 можно загрузить не раньше 31.10.
- **В «Итог ₽» — числа, не формулы.** В «Итог ₽» — число из вашей главной вкладки (Специальная вставка → Значения) или ссылка на её итог. Формулу шаблона не оставляйте: иначе приложение сверит само себя и любая ошибка переноса покажет «сошлось».
- Перед загрузкой сохраните файл в Excel: приложение читает значения, которые Excel запомнил, а не пересчитывает формулы.

## 2. Как откатить неудачный импорт

В Supabase → SQL Editor выполните:

```sql
delete from snapshots where source = 'import';
delete from places p where not exists (
  select 1 from snapshots s, jsonb_array_elements(s.entries) e
  where (e->>'placeId')::uuid = p.id
);
```

Это удаляет все импортированные срезы, но оставляет срезы, введённые в приложении, и места, которые они используют. **Удалятся и места, у которых нет сумм ни в одном оставшемся срезе** — в том числе добавленные в приложении, но ещё не попавшие в срез (например, кошелёк с адресом). Выполните, поправьте файл и импортируйте заново.
